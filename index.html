Definitions, scope & updating

What is being compared

Faculty are drawn from the existing roster and collector output. Rank and appointment type are the roster snapshot, not a faculty member's historical rank in each year. Results describe the careers of currently listed faculty; they are not institution-attributed production. Publication affiliations are not present in the classified export. Roster and match accuracy need review before using results for personnel or resource decisions.

Publications and career impact

Publication counts use the collector's configured publication types. The three authorship roles are mutually exclusive: first author takes precedence, then last author or corresponding author, then co-author. Senior/corresponding is a combined proxy; it cannot be read as a separate count of confirmed corresponding authors. Each paper can credit multiple faculty. Averages divide by every selected year, including zero-publication years, provided a valid annual record exists. Incomplete or uncertain retrievals are unavailable by default.

h-index and total citations are career snapshot values computed from the retrieved works using the collector's exclusion rules. The year filters do not change them. They are database-specific, not Google Scholar values. If incomplete retrievals are enabled, all publication measures and career impact may be lower bounds. Retrieval completeness is checked against expected work counts in cached OpenAlex query metadata when available; absence of a cache does not establish completeness.

Funding

NIH is award amount by fiscal year across all institutions under the current collector configuration. Split credit divides by the number of PIs; full credit assigns the full award to each PI. Neither represents actual faculty expenditures or an individually negotiated budget share. A uniquely matched NIH profile with no award in a year is shown as zero; unmatched or multiple-profile identities are unavailable. API failures may still be present because the annual export lacks per-source request-success flags.

NSF PI amounts are estimated allocations across calendar years, not annual obligations or expenditures. NSF coverage and identity validation are not established by these exports. Selecting NSF or combined funding explicitly includes raw NSF estimates, including zeros for no retrieved awards. Combined funding mixes NIH fiscal years with NSF calendar years and is exploratory. NSF co-PI values are not included. DoD, CPRIT, foundations, industry and other sources are not captured here. Manual other_funding_per_yr averages are shown in individual details and are excluded from year-filtered charts because they have no annual attribution. Funding charts summarize per-person credit; do not sum these into department award totals because shared awards can be duplicated.

How to read coverage

Every bar reports available n / selected n. “No data” means no eligible observations, not no productivity. Comparisons use available faculty, without imputation or weighting. A median over pooled ranks is avoided: all ranks are shown separately by default. No department ranking is inferred when coverage is incomplete. High and override matches still require roster review; an override is a supplied ID, not independent verification. 2026 is an incomplete collection year, excluded by default and never annualized.

Update data without editing code

  1. Edit the existing rosters.csv, overrides.csv and collector config.json as needed. Verify primary, secondary and research appointments consistently across schools.
  2. Resolve OpenAlex author IDs and NIH profile IDs, review API errors and incomplete works, then rerun bme_benchmark.py. Do not run the mock test against production output.
  3. Run python build_dashboard.py --source "path\to\bme_benchmark" in this dashboard folder, or double-click Refresh dashboard.cmd. This checks cached work counts, rebuilds this file and the Power BI tables.
  4. Alternatively choose Load updated data and select faculty_metrics.csv and faculty_by_year.csv together, plus optional config.json. Browser imports are temporary until the page is closed; completeness flags from existing matching IDs are retained, but new identities have unverified retrieval completeness. Rebuild with Python for a durable, audited update.

Power BI

The powerbi folder contains cleaned Faculty, AnnualMetrics and CareerMetrics CSVs, Power Query examples and DAX measures. These use blanks for unavailable values. NSF estimates stay in raw_value until validated. See README.md for relationships and visual setup. This is an import kit, not a completed PBIX report.
